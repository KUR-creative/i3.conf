# i3 설정 관리

이 저장소는 이 컴퓨터의 i3 설정과 관련 보조 도구를 관리한다.

## 작업 문서

- [듀얼 모니터 워크스페이스 개편 계획과 검수 기록](docs/dual-monitor-workspaces.md)

README에는 공통 개발 절차를 기록한다. 특정 변경의 요구사항, 결정, 진행 상황과 검수 결과는 별도 작업 문서에 기록하고 여기에서 연결한다.

## 파일 구성

실행 설정의 진입점은 `~/.config/i3/config`다. 이 파일에서 공통 변수를 정의하고 `include`로 하위 설정을 불러온다.

- `config`: 공통 변수와 명시적인 include 목록.
- `config.d/base.conf`: 일반 키, 레이아웃, 시작 프로그램, bar.
- `config.d/workspaces.conf`: 워크스페이스 변수, 모니터 배정, 전환·이동 단축키.
- `scripts/`: 실제 필요성이 확인된 보조 프로그램. 필요한 단계에서만 생성한다.
- `docs/`: 작업별 계획, 결정 사항, 검수 기록.

## 공통 개발 절차

1. 현재 설정, 적용 중인 단축키, Git 상태와 미커밋 변경을 확인한다.
2. 사용자의 기존 변경을 보존하고 이번 단계의 변경 범위를 명확히 한다. 관계없는 파일이나 기존 변경을 함께 커밋하지 않는다.
3. 한 번에 작은 동작 하나만 구현한다. 구조 변경과 동작 변경은 가능한 한 별도 커밋으로 나눈다.
4. 설정 문법, 중복 바인딩, diff의 오류를 검사한다. 보조 프로그램은 변경 위험에 맞는 검증을 수행한다.
5. 의도한 파일 또는 hunk만 명시적으로 스테이징하고 커밋한다. 자동으로 push하지 않는다.
6. 사용자에게 변경 내용, 커밋, 적용 명령, 작은 재현 순서, 기대 결과와 되돌리는 방법을 알린다.
7. 사용자가 직접 리로드하고 검수한다. 사용자 검수 전에는 다음 동작 변경 단계로 진행하지 않는다.
8. 검수 결과와 발견한 문제를 작업 문서에 기록한다. 문제가 있으면 해결한 뒤 다음 단계로 진행한다.

자동 검증과 사용자 검수는 구분한다. 직접 눌러보지 않은 키 입력이나 실제 사용감을 검증 완료로 기록하지 않는다.

## 설정 검사와 적용

```sh
# 실행 중인 i3를 변경하지 않고 설정 검사
i3 -C -c ~/.config/i3/config

# 사용자가 직접 설정 리로드
i3-msg reload

# 실행 중인 i3가 읽은 설정 파일 확인
i3 --moreversion
```

`reload`는 설정을 다시 읽지만, 이미 존재하는 워크스페이스를 새 이름으로 자동 변경하지 않는다. 일반 `exec` 시작 프로그램도 다시 실행하지 않는다. 필요할 때는 해당 작업에 맞는 별도 이전·재시작 절차를 제공한다.

## include 사용 규칙

- include는 설정을 기능별로 정리하는 용도로 사용한다. 기본 설정을 읽고 뒤에서 같은 키 바인딩을 덮어쓰는 방식으로 사용하지 않는다.
- 같은 바인딩을 여러 파일에 중복 정의하지 않는다. 기존 정의를 목적 파일로 옮긴다.
- 공통 변수는 메인 파일에서 include보다 먼저 정의한다.
- 포함 파일에서 정의한 변수는 상위 파일에서 사용할 수 없으므로, 기능별 변수와 이를 참조하는 설정은 같은 파일 안에 둔다.
- 파일 순서가 중요하면 메인 파일에서 include 목록을 명시한다.

## 작업 보존과 되돌리기

- 편집기 임시 파일과 로컬 백업을 기능 커밋에 포함하지 않는다. 사용자가 편집 중인 파일을 동시에 덮어쓰지 않는다.
- 복구는 대상 커밋의 역변경 등 범위를 한정한 방법을 사용한다. 관계없는 미커밋 작업을 삭제하지 않는다.
- 설정 파일 복구와 실행 중인 창·워크스페이스 상태의 복구는 다르다. 런타임 이름 변경, 공간 이동, 내용 교환은 별도의 복구 계획을 둔다.
- 창을 닫거나 로그아웃하는 작업을 일반적인 설정 적용 절차로 요구하지 않는다.
